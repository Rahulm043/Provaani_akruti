## 4. Key Engineering Guardrails & Solutions

### A. Dormancy & Cold-Start Elimination
1. **Instant Node 1 Greeting Dispatch:** Dispatches `TTSSpeakFrame` directly to TTS on call connect without waiting for LLM round-trip generation.
2. **24/7 Warmup Heartbeat Daemon (`warmup_daemon.py`):** Runs every 10 minutes via cron inside the API container. Pings FastAPI (`/api/v1/health` in 0.05s), Cerebras LLM (0.47s), and Smallest TTS (0.38s). Keeps TLS sessions, DNS caches, and DB connection pools perpetually warm.
3. **Linux Kernel Memory Hardening:** Configured `vm.swappiness = 10` to prevent Linux from swapping active voice engine processes to disk during idle periods.

### B. UI & Frontend Observability
1. **Mobile Responsive Audio Player:** Full-width scrub track, time elapsed badge, volume control, and direct WAV download.
2. **2-Column Telemetry Grid:** Real-time extraction of TTFB (~350ms), latency (1.5s), detected language, queried procedure, and booking status.
3. **Branding & Assets:** Tab title explicitly set to **`Provaani`** with the official `/logo.jpg` favicon.

### C. Custom Subdomain & SSL/TLS
1. **Custom Domain:** `https://akruti.provaani.xyz` backed by Let's Encrypt SSL certificate.
2. **Nginx Ingress:** Port `443` HTTPS (HTTP/2 enabled) + Port `80` HTTP with wildcard `*.provaani.xyz` routing.
